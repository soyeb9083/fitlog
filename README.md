# FitLog

A dark-themed, modern, and no-nonsense gym companion app designed to help users browse exercises, log workouts, and track their fitness progress seamlessly.

---

## 🛠️ Technologies Used

* **Framework:** Next.js (App Router)
* **Library:** React, React Context API
* **Styling:** Tailwind CSS, DaisyUI
* **Icons:** Lucide React
* **Language:** TypeScript
* **State Management:** React Context API (LibraryContext)

---

## ✨ Key Features

1. **Exercise Library Navigation:** Browse a comprehensive collection of workouts categorized across major muscle groups with an intuitive layout.
2. **Interactive Plan Builder:** Effortlessly add or remove specific lifts to customize your daily workout plan in real time.
3. **Save & Bookmark Workouts:** Easily bookmark your favorite exercises for quick access and future reference.
4. **Dynamic Active Route Highlighting:** Interactive navigation bar that automatically detects and highlights your current page location for seamless navigation.
5. **Responsive Dark-Themed UI:** A high-performance, dark-mode design engineered for mobile, tablet, and desktop screens.
